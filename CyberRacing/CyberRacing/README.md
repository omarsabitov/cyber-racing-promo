# CYBER RACING — учебный промо-сайт

Три страницы: `index.html` (главная), `prices.html` (тарифы), `contacts.html` (контакты и демонстрационная форма).

## Технологии и интерактивность
- HTML5, CSS3, JavaScript.
- Анимация появления блоков при прокрутке через `IntersectionObserver`.
- События мыши `mousemove`, `mouseenter`, `mouseleave`.
- Клавиатурные события `keydown`: стрелки переключают тарифы, клавиша `?` запускает подсветку; `Tab` и `Enter` позволяют работать с интерактивными элементами.
- Мобильное меню, проверка полей формы, предварительный выбор тарифа через URL.
- Адаптивная вёрстка для небольших экранов.

## Запуск локально
Откройте папку в VS Code и откройте `index.html` в браузере. Можно установить расширение Live Server и нажать **Go Live**. Node.js не требуется.

## Публикация на GitHub Pages
1. Создайте публичный репозиторий `cyber-racing-promo` на GitHub.
2. Загрузите содержимое папки проекта в корень репозитория (не ZIP-файл вместо содержимого).
3. Перейдите в **Settings → Pages**.
4. В **Build and deployment** выберите **Deploy from a branch**, ветку `main` и папку `/(root)`, затем нажмите **Save**.
5. Дождитесь публикации. Если имя аккаунта — `JefeOmar102`, ожидаемый адрес сайта: `https://jefeomar102.github.io/cyber-racing-promo/`.

Ссылки заработают только после фактического создания репозитория, загрузки файлов и включения GitHub Pages. Форма контактов демонстрационная: она проверяет поля в браузере и не отправляет данные на сервер. Цены и контакты вымышлены для учебного макета.
